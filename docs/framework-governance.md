# Framework Versus Governance

## Framework

A framework defines the loop: elements, roles, transitions, inputs, outputs, and feedback relationships.

A framework is not itself an assurance mechanism.

## Governance

Governance defines controls placed within or around the loop. This repository defines governance through explicit gates that regulate transitions, outputs, or state changes.

Working notation:

```text
Framework = Loop
Governance = Loop + Gates
```

This relationship is provisional. The notation means that gate structure is being treated as an architectural layer rather than a property of a single participant.

## Calibration

Calibration is an evaluated property of system behavior. It may emerge from:

- participant capability
- protocol structure
- gate enforcement
- feedback timing
- topology
- interaction context

The working hypothesis is that governance can change calibration outcomes, but no such causal effect is established yet.
