# Open Questions

## Ontology

- What formally distinguishes a tool from a participating machine?
- Is role, ontology, or autonomy the best basis for M?
- Can category membership change with context?
- When does a human-operated tool become a participant?

## Architecture

- Is governance distinct from the framework, or a property of the framework?
- What constitutes a feedback loop versus ordinary turn-taking?
- Which topologies are materially different for calibration outcomes?
- Can topology effects be separated from participant and model effects?

## Gates

- What gate triggers are necessary and sufficient?
- Are candidate gates independent, sequential, or overlapping?
- How should gate failure and override be coded?
- How can silent gate failure be detected?
- Does every correction event indicate a useful gate, or can correction be harmful overhead?

## Calibration

- Is calibration a participant property, architecture property, or both?
- Which metric captures calibration rather than confidence compression or conservatism?
- How should calibration be measured across hypotheses rather than isolated conclusions?
- Can preserving creativity be measured independently of calibration?

## Replication

- Which effects generalize across model families?
- Which effects depend on prompt style, interface, or participant expertise?
- Can third-party reviewers reproduce metric coding from this repository alone?
